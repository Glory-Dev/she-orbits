Python for Orbital Mechanics is a specialized technical course designed to bridge programming and aerospace engineering. Participants develop practical Python skills while exploring orbital mechanics, satellite trajectories, mission planning, numerical methods, simulation, and data visualization. Through hands-on exercises and aerospace applications, learners build computational models and apply programming techniques to real-world orbital engineering scenarios, preparing them for further study and technical work within the space sector.

## Topics covered

- Orbital mechanics
- Satellite trajectories
- Numerical methods
- Data visualization
- Mission planning

## Sessions & milestones

- Python foundations for aerospace
- Orbit simulation labs
- Trajectory challenge
- Capstone model review
